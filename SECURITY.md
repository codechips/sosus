# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting flow for this repository instead. Include a
clear description, affected version, reproduction steps, and any proof of
concept needed to evaluate the impact.

We will acknowledge a report promptly, investigate it privately, and coordinate
a fix and disclosure with the reporter where practical.

## Scope

sosus handles recordings, transcripts, local configuration, model downloads,
and macOS capture permissions. Reports involving unintended data disclosure,
unsafe file handling, model-download integrity, release signing/notarization,
or capture permission behavior are particularly useful.
